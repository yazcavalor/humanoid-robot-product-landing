## 🧠 Overview

**Objective:**  
Design and build a modern, responsive landing page that demonstrates the robot’s capabilities using 3D visuals, animations, and storytelling.

**Design Goals:**
- Blend *futuristic tech* with *human warmth*
- Use *interactive 3D scenes* to engage users
- Deliver a *smooth, accessible* experience across devices

---

## 🧩 Tech Stack

| Category | Tools / Libraries |
|-----------|------------------|
| Frontend | React 18, Create React App |
| 3D Graphics | React Three Fiber, Drei |
| Animations | Framer Motion |
| Icons | Lucide React |
| Styling | Vanilla CSS (Glassmorphism, gradients) |
| Design | Figma |

---

## 💡 Key Features

| Feature | Description |
|----------|--------------|
| 🦾 **3D Hero Section** | Interactive robot built with React Three Fiber |
| 💬 **Meet Assistant** | Animated robot face & personality traits |
| 🎚️ **Task Comparison** | Before/after slider showing robot efficiency |
| 🎥 **Video Carousel** | Responsive gallery with modal video playback |
| 🧵 **Story Scroll** | Scroll-triggered development timeline |
| ✅ **Trust Validation** | Partners, testimonials, and credibility indicators |
| 🚀 **Call to Action** | Pre-order CTA with animations and urgency triggers |
