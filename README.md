## 🎯 About The Project

A modern, interactive landing page designed for Asimov Robotics' flagship humanoid robot product. This project showcases advanced web technologies including 3D graphics, smooth animations, and responsive design to create an engaging user experience that balances futuristic aesthetics with approachable, humanized interactions.

### The Challenge

> *"Design the homepage for a robotics startup launching its flagship humanoid robot — capable of assisting in homes, hospitals, and retail."*

### The Solution

Built a fully responsive, interactive landing page featuring:
- **3D Interactive Robot** using Three.js and React Three Fiber
- **Scroll-Triggered Animations** with Framer Motion
- **Before/After Comparison Slider** for value demonstration
- **Video Carousel** with lightbox functionality
- **Responsive Design** optimized for all devices

**Target Audience:** B2C homeowners, B2B healthcare and retail businesses, tech enthusiasts

## 🚀 Getting Started

### Prerequisites
```bash
Node.js (v14.0.0 or higher)
npm or yarn
Git
```

### Installation

1. **Clone the repository**
```bash
   git clone https://github.com/your-username/asimov-robotics-landing-page.git
```

2. **Navigate to project directory**
```bash
   cd asimov-robotics-landing-page
```

3. **Install dependencies**
```bash
   npm install
```

4. **Start development server**
```bash
   npm start
```

5. **Open in browser**
```
   http://localhost:3000
```

### Build for Production
```bash
npm run build
```

## 💡 What I Learned

### Technical Skills

**React Fundamentals**
- Mastered useState and useEffect hooks
- Understood Virtual DOM and component lifecycle
- Learned efficient state management patterns

**Three.js/3D Graphics**
- First experience with 3D coordinate systems
- Implemented interactive 3D models with React Three Fiber
- Synchronized multiple animations (floating, mouse tracking, click interactions)

**CSS Architecture**
- Discovered CSS specificity and cascade principles
- Implemented BEM-inspired naming conventions
- Built complex layouts with Flexbox and Grid

**Responsive Design**
- Debugged complex responsive breakpoint issues
- Learned mobile-first development approach
- Understood desktop vs. mobile interaction paradigms

### Problem-Solving Wins

**Challenge: 3D Robot Animation**
- **Issue**: Inverted waving motion and complex animation timing
- **Solution**: Debugged coordinate system, synchronized animations with useFrame
- **Learning**: 3D requires different mental model than 2D web dev

**Challenge: CSS Conflicts**
- **Issue**: Global styles overriding component styles
- **Solution**: Implemented component-prefixed class naming
- **Learning**: Discovered CSS specificity hierarchy and importance of naming conventions

**Challenge: Responsive Robot Face**
- **Issue**: Component breaking at mobile breakpoints
- **Solution**: Systematic debugging revealed incorrect max-width values
- **Learning**: Simple solutions often hide behind complex assumptions

### Professional Growth
- Adopted design-first workflow (Figma → Code)
- Learned when to simplify features for reliability
- Developed systematic debugging methodology
- Built confidence in learning new technologies independently
